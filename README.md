# Experiment Analysis Framework

Developed by Ritu Raj Singh

## Project Overview

This project presents an experimentation analysis framework designed to evaluate Control and Treatment groups using key experiment metrics and statistical checks.

The analysis focuses on conversion performance, user distribution, revenue, statistical significance, confidence intervals, and Sample Ratio Mismatch (SRM) checking.

## Data Preparation

The raw dataset was cleaned in *Microsoft Excel* before analysis and visualization. Data quality checks included handling missing values, removing duplicate records, standardizing fields, and preparing the dataset for analysis.

Python was used for analysis after the Excel cleaning process, while Tableau was used to create the final dashboard.

## Analysis Performed

* Control vs Treatment conversion analysis
* User distribution by experiment variant
* Revenue analysis
* Conversion lift calculation
* Statistical significance testing
* Confidence interval analysis
* SRM check
* Device-level conversion analysis
* Date-wise conversion trend
* Automated experiment readout

## Dashboard

The Tableau dashboard provides an interactive view of experiment performance, including:

* Variant Conversion
* Users by Variant
* Revenue by Variant
* Daily Conversion Trend
* Device Conversion
* Experiment Readout

## Project Outcome

The framework provides a structured way to evaluate an experiment and identify whether observed differences between Control and Treatment groups require further investigation based on statistical and data-quality checks.
